# Accessibility Statement

We are committed to making this educational resource accessible to all learners, including those with disabilities.

## Our Commitment

This website is designed to be accessible according to the Web Content Accessibility Guidelines (WCAG) 2.1 AA standards.

## Accessibility Features

- Semantic HTML structure for proper screen reader navigation
- Sufficient color contrast ratios
- Keyboard navigation support
- Alternative text for images
- Proper heading hierarchy
- Form elements with appropriate labels

## Ongoing Efforts

We continuously work to improve accessibility and welcome feedback about accessibility issues.
