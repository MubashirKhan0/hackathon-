# Module 2: The Robotic Nervous System & Digital Body

This module explains how robots are structured internally and coordinated through software. You'll learn about ROS 2 architecture and how digital robot bodies are represented using URDF and SDF formats.

## Chapters in this Module:

1. [The Robotic Nervous System (ROS 2)](./chapter-1.md)
2. [Nodes, Topics, Services, and Actions](./chapter-2.md)
3. [Digital Robot Bodies (URDF & SDF)](./chapter-3.md)

## Learning Objectives:

- Understand the architecture of robotic software systems (ROS 2)
- Learn about communication patterns in robotics (nodes, topics, services, actions)
- Comprehend how robots are represented digitally (URDF & SDF)
